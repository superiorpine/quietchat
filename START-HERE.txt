QUIETCHAT ДЛЯ IPHONE — БЫСТРАЯ УСТАНОВКА

1. РАСПАКУЙТЕ АРХИВ
   Внутри папки QuietChat-iPhone лежат готовые файлы сайта.
   Загрузка самого ZIP на GitHub не запускает приложение.

2. СОЗДАЙТЕ РЕПОЗИТОРИЙ
   Откройте https://github.com/new и войдите в бесплатный аккаунт.
   Имя: quietchat. Доступ: Public. Включите Add README.
   Нажмите Create repository.

3. ЗАГРУЗИТЕ ФАЙЛЫ
   В репозитории: Add file → Upload files.
   С компьютера перетащите СОДЕРЖИМОЕ папки QuietChat-iPhone:
   файлы и папки vendor, icons, tests. Сохраните в ветку main.
   index.html должен быть сразу в корне, рядом с README.md.
   Если нет скрытого файла .nojekyll, создайте его через
   Add file → Create new file; содержимое: QuietChat static files.

   Если есть только iPhone, загрузите основные файлы в корень.
   Затем создайте vendor/README.txt, зайдите в папку vendor
   и загрузите в неё файлы библиотеки из архива.
   Так же создайте icons/README.txt и загрузите три PNG в icons.
   Подробные шаги для телефона — в README.md, раздел 2.

4. ВКЛЮЧИТЕ САЙТ
   Settings → Pages → Source: Deploy from a branch.
   Branch: main. Folder: /(root). Нажмите Save.
   Дождитесь ссылки Visit site — обычно до 10 минут.
   Адрес: https://ВАШ_ЛОГИН.github.io/quietchat/

5. УСТАНОВИТЕ НА IPHONE
   Откройте ссылку в Safari, не во встроенном браузере Telegram.
   Поделиться → На экран «Домой» → Добавить.
   Если есть переключатель «Открывать как веб-приложение», включите.
   Запускайте QuietChat с появившейся иконки.
   Рекомендуется iOS 17 или новее.

6. СОЗДАЙТЕ СВОЙ ПРОФИЛЬ
   Пароль — минимум 12 символов. Сброса пароля нет.
   Профиль → Сохранить резервную копию → Сохранить в Файлы.
   Дождитесь готовности работы без интернета во вкладке «Профиль».
   Создавайте профиль после запуска с иконки; Safari может иметь
   отдельное хранилище. Перенос профиля — через зашифрованную копию.

7. ДОБАВЬТЕ ДРУГА
   Друг устанавливает приложение по той же ссылке и создаёт свой ключ.
   Оба: Мой ключ → Копировать → отправить публичную строку QCK1:… .
   Друзья → Добавить → имя → публичный ключ друга.
   Сверьте ВСЕ группы отпечатка по звонку или при встрече.
   Только после этого отметьте проверку и сохраните контакт.
   Публичный ключ передаётся один раз; приватный ключ остаётся у вас.

8. ПЕРЕПИСЫВАЙТЕСЬ
   Отправить → друг → текст → Зашифровать → Поделиться → Telegram.
   Или: Копировать → вставить в Telegram вручную.
   Получатель: копирует QC1:… из Telegram → Прочитать → вставляет.
   Для длинного сообщения: Сохранить сообщение в файл и отправить .qcm.
   Если кнопка вставки не работает, удерживайте палец в поле → Вставить.

НЕ ЗАГРУЖАЙТЕ НА GITHUB свои пароли и файлы .qcbkp/.qcvault.
Резервную копию не отправляют другу. Сохраните её отдельно от телефона.
Эта версия не проходила независимый аудит и не содержит Double Ratchet.
Ограничения, восстановление и подробная инструкция — в README.md.

Настоящие установка с иконки и меню Telegram требуют проверки на iPhone.
Криптография, совместимость с Python и интерфейс WebKit проверены отдельно.
